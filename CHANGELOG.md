# Changelog

Todas as mudanças notáveis neste projeto serão documentadas aqui.

O formato segue [Keep a Changelog](https://keepachangelog.com/pt-BR/1.0.0/),
e este projeto adere ao [Versionamento Semântico](https://semver.org/lang/pt-BR/).

## [1.0.0] — 2025

### Adicionado
- Plataforma web interativa (`plataforma/curso_data_science.html`) com navegação completa pelos 10 módulos
- Conteúdo manual completo das **Semanas 1 e 2** (Módulo 1 — Fundamentos):
  - Resumo didático com exemplos brasileiros
  - Curadoria de 5 vídeos por semana (PT-BR prioritário)
  - Repositórios GitHub de referência
  - Livros e capítulos recomendados
  - Artigos acadêmicos e essays
  - Datasets para prática (Kaggle, dados.gov.br)
  - Exercícios em 3 níveis (básico, intermediário, portfólio)
  - Cronograma de aula de 2 horas
  - Recursos adicionais (podcasts, comunidades, newsletters)
- **Projeto do Módulo 1** com checklist interativo e script de entrevista
- Geração de conteúdo por IA (Claude API) para semanas 3–40 via botão na plataforma
- `README.md` completo com estrutura, badges e guia de uso
- `CONTRIBUTING.md` com padrões de conteúdo e processo de PR
- `LICENSE.md` — MIT (código) + CC BY 4.0 (conteúdo)
- `CHANGELOG.md` (este arquivo)
